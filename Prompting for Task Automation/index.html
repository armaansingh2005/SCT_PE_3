Prompt Engineering Reflection

Documentation of prompt design, testing and iteration.

Problem

Initial prompts produced inconsistent outputs. Some responses omitted important fields while others returned extra information not required by the schema.

Iteration 1

Used a simple prompt: "Convert text into JSON." Results varied significantly and lacked consistency across different inputs.

Iteration 2

Added field extraction requirements and a predefined output structure. Reliability improved but some fields were still missing.

Iteration 3

Added strict schema constraints, formatting rules and validation checks. Outputs became highly consistent and easier to parse programmatically.

Final Result

Reliability improved from approximately 60% to 95% through prompt refinement, schema enforcement and testing against multiple real-world examples.

Key Learnings

  • Clear instructions improve consistency.
  • Explicit schemas reduce ambiguity.
  • Prompt iteration is essential for reliable automation.
  • Structured outputs are easier to integrate into software systems.
